# 매일 갱신 도구

앱의 중개업소 목록과 구역별 호가를 매일 다시 확인해서 고치는 데 쓰는 파일들이에요. 예약 작업(Claude)이 아침마다 실행합니다.

| 파일 | 하는 일 |
|---|---|
| `browser-snippets.js` | 내 컴퓨터의 브라우저에서 실행하는 코드 조각. 서울시 등록부와 재개발닷컴을 읽고, 지금 올라가 있는 데이터와 **다른 것만** 돌려줘요. |
| `apply-update.js` | 그 "다른 것"(patch.json)을 `data.js`, `data-guui.js`, `listings.js`, `updated.js`에 반영해요. |

## 규칙

- 등록부에서 사라진 중개업소는 바로 지우지 않고 "등록부에서 사라짐" 표시를 붙여요. 30일이 지나도 돌아오지 않으면 목록에서 빠져요. (리뷰와 각자 메모가 그 중개업소 id에 붙어 있어서예요)
- 새로 등록된 곳은 같은 길에 있는 기존 중개업소와 같은 묶음에 넣고 14일 동안 "새로 등록" 표시를 붙여요.
- 매물은 구역별 유형과 호가만 가져와요. 새로 올라온 것은 7일 동안 "새로" 표시가 붙어요.
- 한꺼번에 너무 많이 바뀐 것으로 나오면(읽기 실패 가능성) 그날은 반영하지 않아요.

## 구역을 추가했을 때

- 중개업소: `browser-snippets.js`의 `SRC`와 `apply-update.js`의 `AREAS`에 구역을 추가하고, 데이터 행 9번째 칸에 등록번호를 넣어요.
- 매물: `listings.js`의 `areas`에 재개발닷컴 구역 id를 추가해요.
