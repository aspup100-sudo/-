# 임장 수첩

재개발·재건축 구역을 돌 때 쓰는 수첩입니다. 첫 화면에서 구역(창신, 구의)을 고르면 그 구역의 중개업소, 구역 정보, 후보 매물, 동선이 나오고, 휴대폰 홈 화면에 앱처럼 설치할 수 있어요.

- **나만 보는 것**: 통화·방문 체크, 메모, 받아온 번지, 동선에 담은 곳. 각자 기기에만 저장되고 서버로 가지 않아요.
- **회원이 같이 보는 것**: 중개업소 리뷰(별점, 친절도, 허위매물 여부, 후기). 이메일·비밀번호·닉네임으로 가입하고, 한 회원이 한 곳에 하나씩 써요. 쓴 회원만 고치거나 지울 수 있어요.
- **로그인**: `config.js`의 `requireLogin`이 true면 로그인해야 앱이 보여요. 비밀번호를 잊으면 가입한 이메일로 재설정 링크를 받아 새로 정해요.
- **지도와 동선**: 카카오 지도에 중개업소를 점으로 찍고, "동선 담기"로 고른 곳을 가까운 순서로 이어 걷는 시간을 어림해요.

## 서울 전체

첫 화면의 "서울 전체에서 고르기"에서 구와 동을 고르면, 그 동에 등록된 중개업소가 지도와 함께 나와요. 자료는 서울 열린데이터광장의 "서울시 부동산 중개업소 정보"이고 `data/gu/<구코드>.json`에 구별로 들어 있어요. 고른 구의 파일만 그때 받아옵니다. `tools/build-seoul.js`가 받은 자료를 이 파일들로 만들어요.

## 파일 구성

| 파일 | 내용 | 고칠 때 |
|---|---|---|
| `index.html` | 화면 뼈대, 약도(SVG), 질문 목록, 구역 메모 | 문구나 구성 변경 |
| `styles.css` | 색, 글꼴, 간격 | 디자인 변경 (맨 위 `:root`의 색 값) |
| `seoulmap.js` | 첫 화면의 서울 약도 (구 모양과 이름 자리) | 약도 모양을 바꿀 때 |
| `areas.js` | 구역 정보까지 정리한 동(창신, 구의), 물어볼 것 | 구역 추가, 구역 정보 수정 |
| `data.js`, `data-guui.js` | 정리해 둔 구역(창신, 구의)의 중개업소와 매물 목록 | 매물·업소 추가, 수정 |
| `data/gu/*.json` | 서울 전체 중개업소 (구별, 자동 생성) | 손대지 않음 |
| `boot.js` | 주소를 보고 필요한 자료를 받은 뒤 앱을 시작 | 보통 손댈 일 없음 |
| `map.js` | 카카오 지도, 주소→좌표 변환 | 지도 표시 변경 |
| `route.js` | 동선 순서와 시간 계산 | 걷는 속도, 계산 방식 변경 |
| `app.js` | 체크, 메모(기기 저장), 걸러 보기, 설치 버튼 | 기능 변경 |
| `reviews.js` | 리뷰 쓰기와 보기 | 리뷰 항목 변경 |
| `config.js` | Firebase 설정, 리뷰 방 이름, 카카오 지도 키 | 처음 한 번 |
| `sync.js` | 리뷰 저장 (Firestore + 익명 로그인) | 보통 손댈 일 없음 |
| `firestore.rules` | Firestore 보안 규칙 | Firebase 콘솔에 붙여넣기 |
| `sw.js`, `manifest.webmanifest`, `icons/` | 설치와 오프라인 | 아이콘·앱 이름 변경 |

## 올리기 (GitHub Pages)

1. GitHub에서 빈 저장소를 만들고 이 폴더의 파일을 전부 올립니다.
2. 저장소 Settings → Pages → Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 두고 저장합니다.
3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소로 열립니다. 이 주소를 같이 쓸 사람에게 보내면 됩니다.

## 리뷰 켜기 (Firebase)

1. https://console.firebase.google.com 에서 프로젝트를 만듭니다.
2. Firestore Database → 데이터베이스 만들기 → 위치 `asia-northeast3 (서울)` → 프로덕션 모드.
3. Firestore의 규칙 탭에 `firestore.rules` 내용을 그대로 붙여넣고 게시합니다.
4. Authentication → 시작하기 → 로그인 방법에서 **이메일/비밀번호**를 사용 설정합니다. (비밀번호 재설정 메일을 한국어로 보내려면 Authentication → 템플릿에서 언어를 한국어로 바꿔요.)
5. 프로젝트 설정 → 내 앱 → 웹 앱의 `firebaseConfig` 값을 `config.js`에 넣습니다.

## 지도 켜기 (카카오)

1. https://developers.kakao.com 에서 앱을 만들고, 제품 설정의 **카카오맵**을 사용 설정합니다.
2. 플랫폼 키의 JavaScript 키에 사이트 주소(`https://아이디.github.io`)를 등록합니다.
3. JavaScript 키를 `config.js`의 `kakaoKey`에 넣습니다.

키가 없거나 지도를 못 불러오면 지도와 동선 계산만 꺼지고 나머지는 그대로 동작해요.

## 구역 추가하기

1. `data-○○.js`에 중개업소 목록을 만듭니다. (서울부동산정보광장 등록부 기준, 행 형식은 `data-guui.js` 참고)
2. `areas.js`에 구역 덩어리를 추가하고 `order`에 id를 넣습니다.
3. `index.html`과 `sw.js`의 파일 목록에 새 데이터 파일을 추가합니다.

## 알아둘 점

- 주소를 아는 사람은 누구나 리뷰를 보고 쓸 수 있습니다. 리뷰에는 직접 겪은 사실만 적고, 개인정보는 적지 마세요.
- 체크와 메모는 기기에만 있어서, 휴대폰을 바꾸거나 브라우저 데이터를 지우면 사라집니다.
- 익명 로그인도 기기별이라, 브라우저 데이터를 지운 뒤에는 예전에 쓴 리뷰를 고칠 수 없습니다. (Firebase 콘솔에서는 지울 수 있어요)
- `?room=이름`을 주소 뒤에 붙이면 별도의 리뷰 방이 열립니다. (예: `.../?room=family`)
- 설치: 안드로이드 크롬은 "홈 화면에 설치" 버튼, 아이폰 사파리는 공유 → 홈 화면에 추가.
- 중개업소 목록은 서울시 부동산중개업 등록부(2026-10-09 조회) 기준입니다.
